# Averon System

Crie um sistema web completo de gestão comercial e técnica para minha empresa de refrigeração chamada MEC Frio Refrigeração.

O sistema deve funcionar como um CRM profissional, mas também como uma plataforma de gestão de serviços técnicos de refrigeração.

1. IDENTIDADE VISUAL

Nome da empresa:
MEC Frio Refrigeração

Criar uma interface profissional, moderna e responsiva.

Paleta principal:

Azul-marinho como cor principal

Preto/grafite para fundos e elementos secundários

Branco para textos

Azul mais claro para destaques e botões

A aparência deve transmitir:

Profissionalismo

Confiança

Organização

Assistência técnica especializada

Empresa de refrigeração profissional
